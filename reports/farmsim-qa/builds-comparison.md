# Задание №1 - Сравнение билдов (3-колоночный вариант, черновик)

**Метод:** статический анализ обоих APK (Android Studio → Analyze APK + Compare with previous APK; `apksigner`). Без запуска. Раздел «Сеть» по Test1 дополнен точными эндпоинтами из динамического перехвата в Fiddler.

Основные характеристики сравнения: идентификационная информация, сборка, разрешения, контент внутри билдов, сеть, соответствие требованиям сторов.

## Резюме

Оба APK - **одна и та же игра и одна версия (0.7.0 / code 1700)** в двух вариантах сборки. Контент, код, SDK, подпись и бэкенд практически идентичны; при одинаковом versionCode билды собраны с разницей примерно 4 года. Test1 новее.

## Вердикт

**Ни один билд не готов к релизу:** оба отладочные (`debuggable=true`), targetSdk ниже требований Google Play (35), содержат dev-консоль Lunar Console, доверяют user-CA, смотрят на QA-бэкенд; Test2 вдобавок только 32-бит. **Test1 ближе к релизу** (64-бит, target выше) - его буду тестировать на физическом устройстве.
