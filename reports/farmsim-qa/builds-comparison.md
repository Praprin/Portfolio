# Assignment #1 - Build Comparison (3-column version, draft)

**Method:** static analysis of both APKs (Android Studio → Analyze APK + Compare with previous APK; `apksigner`). No execution involved. The "Network" section for Test1 is supplemented with exact endpoints from dynamic interception in Fiddler.

Main comparison characteristics: identification info, build, permissions, content inside the builds, network, store compliance.

## Summary

Both APKs are **the same game and the same version (0.7.0 / code 1700)** in two build variants. Content, code, SDKs, signature, and backend are practically identical; with the same versionCode, the builds were built roughly 4 years apart. Test1 is newer.

## Verdict

**Neither build is release-ready:** both are debug builds (`debuggable=true`), targetSdk is below Google Play's requirement (35), both include the Lunar Console dev tool, both trust the user-CA, both point at the QA backend; Test2 is additionally 32-bit only. **Test1 is closer to release** (64-bit, higher target) - it will be the one tested on the physical device.
