## Совместимость (только эмулятор)

Секция прогоняется **только на AVD** (реальному устройству тут нечего проверять). Смоук эмулятора - в колонке «Эмулятор» таблицы SMOKE выше.

> **Ограничение среды:** в текущей Android Studio образы эмулятора ограничены превью-API 37 - матрица старых версий Android не покрыта. Современные конфигурации покрыты реальным устройством (Xiaomi 12T Pro, API 35). APK только ARM: на x86_64-образе (API >= 30) игра идёт через встроенную ARM-трансляцию. **Единственный доступный образ - 16-КБ page size, на нём игра крашится (BUG-009), поэтому визуальные проверки ниже провести не удалось.**

| Проверка                                                                  | Эмулятор | Коммент                                                                                                                                                                      |
| ------------------------------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Устройство с вырезом/notch: UI в safe area, ничего не режется             | Blocked  | игра не стартует на 16-КБ образе (BUG-009)                                                                                                                                   |
| Планшет / ландшафт: верстка не растянута и не обрезана                    | Blocked  | то же                                                                                                                                                                        |
| Разные разрешения/DPI: нет наложений и битых спрайтов                     | Blocked  | то же                                                                                                                                                                        |
| Прерывания через Extended Controls (звонок/сеть/батарея)                  | Blocked  | то же                                                                                                                                                                        |
| 16-КБ образ: игра запускается (проверка находки «Does not support 16 KB») | Fail     | краш на старте: UnsatisfiedLinkError, libmain.so, alignment 8192 < 16384 - [BUG-009](../../bug-reports/farmsim-qa/BUG-009%20-%2016KB_Page_Size_Incompatible.md) (подтверждает находку из Задания №1) |

## Анализ сетевого трафика (Fiddler)

Динамический перехват HTTPS-трафика билда **Test1** на реальном устройстве (Xiaomi 12T Pro).

**Метод:** прокси Fiddler на ПК, телефон по Wi-Fi ходит через прокси; корневой сертификат Fiddler установлен как пользовательский CA. Сборка **доверяет user-CA** (находка F-09), поэтому перехват удался

**Подтверждённые хосты игры** (атрибуция по SDK-специфичным доменам):

- **Unity Ads:** config.unityads.unity3d.com, publisher-config.unityads.unity3d.com, httpkafka.unityads.unity3d.com, cdp.cloud.unity3d.com, config.uca.cloud.unity3d.com
- **Facebook / Meta SDK:** graph.facebook.com, graph-fallback.facebook.com, graph.fbpigeon.com
- **Firebase:** firebaselogging.googleapis.com
- **Гео / Google API:** freegeoip.app, play-fe.googleapis.com, spot-pa.googleapis.com
- **Из статики (strings/arsc):** farmsim-qa.firebaseio.com, farmsim-qa.appspot.com

**Выводы:**

- **Unity Ads реально ходит в сеть** → реклама присутствует (уточняет находку в статике).
- Игра шлёт данные сторонним сервисам (Unity Ads, Facebook, Firebase) → подтверждает находку F-08; должно быть отражено в Data Safety / App Privacy.
- **F-09 подтверждена практикой** (доверие user-CA → перехват возможен).
