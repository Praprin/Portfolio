# BUG-007 - Одновременно звучат 2 и более музыкальные дорожки при использовании сыроварни (начиная с уровня 15)

| Поле                 | Значение                                                           |
| -------------------- | ------------------------------------------------------------------ |
| **Type**             | Functional (Audio)                                                 |
| **Severity**         | Minor                                                              |
| **Priority**         | Medium                                                             |
| **Status**           | Open                                                               |
| **Affects build**    | Test1 (v0.7.0 / code 1700)                                         |
| **Environment**      | Xiaomi 12T Pro, Android 15 (API 35), arm64                         |
| **Component / Area** | Audio / музыка (использование сыроварни, уровень 15)               |
| **Reproducibility**  | Once (наблюдался 1 раз; требует повтора через debug -> уровень 15) |

## Предусловия

Игрок на 15 уровне (первое появления сыроварни в игре), меню запуска Уровня 15 (видим кнопку с номером уровня)

## Шаги воспроизведения

1. Начать уровень 15  и в начале геймплея наблюдать новый туториал (использование сыроварни).
2. Завершить туториал, т.е. отправить бутылку молока в сыроварню
3. Слушать музыку - сразу после активации процесса сыроварни, запускается еще один трек трек с музыкой (другой)
4. Отправить в сыроварню еще одну бутылку молока - слушать музыку, запускается еще один слой той же самой музыки

## Ожидаемый результат

В уровне играет только одна музыкальная дорожка (уровневая). Музыка, звучавшая во время туториала (или в меню выбора уровня), корректно останавливается по его завершении - наложения двух треков нет.

## Фактический результат

После завершения туториала и активации сыроварни, начинает звучать еще один музыкальный трек и они продолжают воспроизводиться постоянно оба. Если воспользоваться сыроварней еще раз - слышно, как включается еще одна копия того же трека. И если повторить это снова - еще одна копия. Предположительно слышно сразу 4 трека одновременно (повышение общего уровня громкости каждый раз и добавление еще звуков музыки);
